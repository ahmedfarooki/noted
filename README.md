## Organization

Notes live in topic folders, with a subfolder when it helps narrow the subject:

```text
audio/
  transcription/
    google-talk-with-whisper.md
```

Use lowercase, hyphenated names for folders and Markdown files. Name each note after its subject so its purpose is clear from the path. Add new categories as notes need them, and keep the table above updated so every note is easy to find.

## Adding a note

1. Choose the category and, if useful, a subcategory.
2. Create a Markdown file with a descriptive title and filename.
3. Include any prerequisites, steps, examples, and relevant source links.
4. Add the note to the index above.

Keep private information, credentials, recordings, and generated files out of the repository. Review examples before using them and check the licenses of any tools or dependencies mentioned in a note.
